UN CAMBIO A LA VEZ

Mejorar también necesita un orden

Hacer cambios sin saber qué problema se quiere resolver puede hacer perder tiempo. Por eso conviene trabajar de manera simple: observar primero, elegir una mejora concreta y después mirar si realmente produjo un resultado.

Analizá tu negocio

La idea principal

1

Detectá qué problema querés resolver.

2

Elegí una mejora concreta y posible.

3

Medí el resultado y volvé a ajustar.

UN PLAN SIMPLE

Tres pasos para trabajar una mejora

PASO 1

Observá

Detectá qué parte del negocio está generando más problemas o necesita mayor atención. Conviene concentrarse primero en una situación concreta y entender por qué sucede.

PASO 2

Mejorá

Elegí una acción concreta: responder más rápido, ordenar gastos, publicar mejor o revisar un proceso. La mejora tiene que ser posible de realizar y comparar.

PASO 3

Medí

Compará el resultado. Si funcionó, mantenelo. Si no funcionó, probá otra alternativa. Medir permite saber si el cambio realmente ayudó.

SEGUIMIENTO

La mejora no termina con el primer cambio

El proceso puede repetirse todas las veces que sea necesario, pero siempre conviene trabajar sobre un punto concreto para poder entender qué funcionó y qué no.

Revisar

Después de aplicar una mejora, conviene mirar qué pasó y comparar la situación con la anterior.

Mantener

Si una acción dio buen resultado, mantenerla ayuda a que la mejora no se pierda con el tiempo.

Ajustar

Si algo no funcionó como se esperaba, se puede corregir sin tener que cambiar todo el negocio.

Volver a observar

Una vez resuelto un problema, se puede repetir el mismo proceso con otro aspecto.
